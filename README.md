# NurikDz — Native macOS Apps

**Building macOS utilities that feel like they belong on your desktop.**

I build native macOS applications in **Swift** and **SwiftUI**, focused on utility, privacy, and the materials of the Apple ecosystem. Every app is designed for Apple Silicon, ships ad-hoc signed, and distributes cleanly via [Homebrew](https://github.com/NurikDz/homebrew-apps).

---

## Featured Apps

### [ASK](https://github.com/NurikDz/ASK) — Floating AI Assistant
Press a hotkey, ask anything, get an answer. No API key. No subscription. No setup.

### [FreeStream](https://github.com/NurikDz/FreeStream) — Media Streaming Aggregator
High-performance streaming aggregator and media player for macOS. Movies, TV shows, and Live TV in one native SwiftUI interface.

### [TGDrive](https://github.com/NurikDz/TGDrive) — Telegram Cloud Storage
Use your private Telegram channel as cloud file storage. Upload, sync, preview, and download files from a native macOS desktop app.

### [PasteDesk](https://github.com/NurikDz/PasteDesk) — Clipboard Manager on Your Wallpaper
A clipboard manager that lives on your macOS desktop wallpaper — not in the Dock, not in the menu bar. Always visible, never in the way.

### [SentryKit](https://github.com/NurikDz/SentryKit) — Privacy Permission Monitor
Full visibility into the TCC privacy permissions that applications request on your Mac. Stay in control of your data.

### [Tvoiz](https://github.com/NurikDz/Tvoiz) — On-Device AI Audiobook Studio
100% on-device text-to-speech and voice AI for Apple Silicon Macs. No cloud, no subscriptions.

---

## Install Everything via Homebrew

```bash
brew tap NurikDz/apps
brew install --cask ask freestream tgdrive pastedesk sentrykit tvoiz iptvs
```

All apps are **ad-hoc signed** and ship with automatic quarantine stripping — no Apple Developer ID required.
